# Окремий синій хром

На прохання користувача перемикач фону графітового скла прибрано. Графіт знову використовує вихідну чорну сцену. Старий профіль graphite-blue-v1 залишається доступним adapter для старих snapshots.

Третій стиль: preset blue-chrome — дзеркальне dielectric glass із metalness 0, transmission 1, roughness .020, IOR 1.52, поглинанням [8,3,1]. Синя baseColor [.58,.76,1] приймає білі, сині, фіолетові й теплі відбиття; clearcoat 1, iridescence .32, iridescenceIOR 1.7. Темна студія з картами відбиттів, три нерухомі джерела: широке біле, електрично-блакитне та фіолетове. Environment strength 1.05, bloom .025. Фон blue-chrome-studio-v1 має темну майже чорну основу, плавний широкий нижній синій перелив без різкої межі та слабкий центральний ореол.

Це окремий непрозорий дзеркальний матеріал із власним світлом. Вибір зберігає SVG, геометрію, камеру й формат. Зміна кольору conductor змінює baseColor, а не поглинання. Нових залежностей та полів schema немає. Профіль перевіряється у локальному WebGL; відповідність Cycles не заявляється.
