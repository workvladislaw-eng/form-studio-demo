# 0011 — Кут ключового студійного світла

## Проблема

Користувачеві потрібно змінювати напрямок основного світлового променя під час
повороту SVG-об’єкта, зберігаючи однакову поведінку в живому перегляді та експорті.

## Вибір

Сцена зберігає `lighting.keyAngleRad` у межах `[-π, π]`. UI показує це значення
у градусах, а scene-core повертає ключове softbox-джерело навколо вертикальної
осі перед тим, як прив’язати його до орієнтації об’єкта. Стандартне значення — `0`.
Зміна діє для всіх стилів матеріалу; інші джерела зберігають свої ролі заповнення
та контрового світла.

## Наслідки

- кут є частиною версіонованого scene JSON і потрапляє у snapshot експорту;
- UI не містить окремої renderer-логіки;
- старі сцени без поля сумісні: adapter трактує відсутність поля як `0`;
- одиниця зберігання — радіани, щоб уникнути неоднозначності між UI та рендерерами.

## Перевірка

Перевірено unit-тестом, що зміна кута переміщує key light і сцена проходить runtime-валідацію.
