# Графітове скло: чорний фон або синій градієнт

Локальний редактор дає два узгоджені варіанти графітового скла. Чорний відновлює стандартні поглинання та блакитні джерела; синій використовує версіонований background.algorithmVersion=graphite-blue-v1, absorptionPerMeter=[68,38,12], підсилює fill/rim в 1.35 раза і змінює їх на синьо-блакитні. Біла смуга продовжує стежити за об’єктом. Камера, геометрія, глибина та засвіт не змінюються. Вибір фону скидає ручний колір до відповідного пресета.

Фон у linear RGB: майже чорна основа sRGB [0,.015,.035]; нижня діагональна засвітка sRGB [0,.65,1] із маскою 1-smoothstep(-.12,.30,v-.42*u); верхній лівий синій акцент sRGB [.015,.24,.52] із exp(-5*length(u,1-v)). Спільний WebGL shader використовується у перегляді, transmission pass і 4K. Нових полів контракту та залежностей немає. Старі snapshots не змінюються.

Це стилізована студійна подача. Зміна поглинання й кольору джерел узгоджує матеріал із фоном, але не є фізичною симуляцією світіння фону. Профіль призначений для локального WebGL-експорту; відповідність Cycles не заявляється.
