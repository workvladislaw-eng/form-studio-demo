# 0003: Графітове скло зі супроводом світла

На прохання користувача замінює візуальні налаштування ADR 0002. Матеріал — dielectric glass, IOR 1.8, без emission, з графітовим поглинанням та clearcoat. Холодні area lights, без теплого контуру. Bloom: strength 0.12, radius 0.15, threshold 1.

Проблема: нерухомі джерела зникали з дзеркального відбиття під час обертання. Вибір: scene-core обчислює положення трьох softbox-джерел через дзеркальне відбиття напряму камери навколо локальних осей об’єкта. Світові координати записуються в scene JSON; adapters не вводять прихованої зміни світла. Контракт v2 не змінюється. UI керує положеннями автоматично.

Альтернатива: екранна emissive-смуга гарантувала б видимість незалежно від поверхні, але не була б відбиттям. Обрано кероване студійне світло. Для довільних увігнутих форм абсолютної гарантії видимості немає через геометрію та перекриття. Відбиття на фронтальній, зворотній та бічній поверхнях перевіряються в браузері.

Зберігається спільний WebGL composer для preview/4K та рендер лише при зміні. Залежностей не додано.
