# 0012 — Обмежений відтінок для синього хрому

## Проблема

Довільний color picker дозволяє вивести матеріал синього хрому за межі
референсного холодного спектра. Для інших пресетів ручна зміна кольору створює
непередбачені комбінації з їхнім фіксованим освітленням і фоном.

## Вибір

У редакторі ручний контроль кольору доступний лише для `blue-chrome`. Він має
горизонтальну Hue-смугу `0° … 360°` з базовим положенням `215°`, що відповідає
`#073678`; насиченість і світлота залишаються частиною пресета. Для `graphite`
та `amber` окремий контроль кольору не показується.

## Наслідки

- зберігається один контрольований матеріальний параметр без довільного RGB;
- фон синього хрому отримує той самий hue через м’який темний градієнт;
- key, fill і rim автоматично отримують споріднені значення hue зі збереженням
  ролей студійного освітлення;
- інваріанти сцени й експорт залишаються без змін.
