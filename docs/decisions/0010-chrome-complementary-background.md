# Тональний фон для синього хрому

Для preset `blue-chrome` вибраний колір матеріалу є єдиним input. WebGL shader бере той самий hue, зменшує saturation/value та використовує тональний результат у нижньому світловому переливі, верхньому акценті й центральному ореолі. Темна базова складова фону залишається сталою.

Зміна кольору працює через scene JSON: UI записує RGB у `materials[0].baseColor`, а viewer обчислює фон під час оновлення сцени. Тому live preview і 4K export отримують однаковий тональний фон без окремого рендера. Графітове скло та бурштиновий кришталь не змінюють цю поведінку.
