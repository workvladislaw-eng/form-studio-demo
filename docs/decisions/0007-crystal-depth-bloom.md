# Глибина кришталю та керований засвіт

Статус перевірки: TypeScript/Vite build і 22 unit-тести пройдено. Візуальну GPU-перевірку та порівняння 4K не завершено: браузер повертає connection timeout для локального сервера. Cycles-композитор не перевірено в Blender.

Для нових сцен використовується teal-studio-v3: студія та градієнт v2, але матеріал DoubleSide включає задні грані у transmission pass Three.js. Оптична товщина дорівнює локальній глибині mesh; масштаб застосовується шейдером один раз. Старі профілі зберігають попередню поведінку.

Вибір кришталю в редакторі піднімає глибину до 0.320, якщо вона менша. Користувач може знову зменшити її. Фаска 0.010, шорсткість 0.020. Збільшується реальна геометрична товщина, а не тільки затемнення матеріалу.

Scene v2 postprocessing.enhancedBloom — boolean, у нових сценах true. UI не показує перемикач: посилений засвіт є постійною частиною стилю. Відсутнє поле старих сцен також трактується як true; явне false зберігає базову сумісність adapter. Посилений режим задає WebGL bloom strength 0.45. 4K використовує той самий cached bloom pass.

Альтернатива — багатопрохідне трасування внутрішніх відбиттів — не обрана через вимогу швидкого живого перегляду. DoubleSide дає лише наближення; плоска SVG-екструзія з вузькою фаскою не відтворює скульптурний профіль референса. Не заявляємо повну фізичну відповідність або нескінченні внутрішні відбиття. Підтримка backside transmission залежить також від WebGL extensions, як у Three.js 0.186.1.
