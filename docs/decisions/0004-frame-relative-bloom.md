# 0004: Однаковий засвіт у preview та експорті

Причина розбіжності: UnrealBloomPass має фіксовані піксельні blur kernels. Збільшення target до 4K звужувало ореол відносно кадру. Додатково тонкі HDR-відблиски по-різному потрапляли у high-pass при зміні роздільності.

Рішення: робоча роздільність bloom має довгу сторону 960 px для всіх форматів. Перед експортом оновлюємо preview та зберігаємо його готовий ореол. Синхронний 4K render перераховує геометрію, матеріал та відбиття у цільовій роздільності, але додає той самий ореол. Після копіювання кадру відновлюємо звичайний bloom у finally. Нових залежностей та полів scene немає.

Альтернатива: перерахунок bloom у 4K зі збільшеним kernel дорожчий та залежить від субпіксельних відбиттів. Повний апскейл preview неприйнятний через втрату деталей. Тут масштабується лише м’який ореол, а не предмет.

Перевірка: фактично завантажені PNG 301×538 та 2160×3840 на стандартній формі, 9:16. Після зменшення 4K середня абсолютна RGB-різниця на сітці кожні 3 px — 1.645/255. Це не піксельна тотожність: згладжування, transmission та дискретизація геометрії відрізняються. Артефакти: artifacts/bloom-preview.png, bloom-4k.png, bloom-4k-at-preview-size.png.
