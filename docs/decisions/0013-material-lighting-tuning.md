# 0013 — Тонке налаштування світла для трьох пресетів

Для `amber-glass` bloom у live-перегляді знижено до `0.10`, щоб засвіт не
перекривав структуру кришталю. Для графітового скла базове контрове джерело
залишається мінімальним (`1.5 W`) і дає лише тонкий силуетний рефлекс.

Градієнт `blue-chrome` отримав додаткову діагональну світлову смугу. Вона
використовує ті самі кольори, що й Hue-повзунок, тому фон, ореол і студійне
освітлення змінюються узгоджено.
