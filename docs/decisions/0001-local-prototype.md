# 0001 — локальний наскрізний прототип

Дата: 2026-10-04. Статус: реалізовано, калібрування якості триває.

Мета — перевірити SVG → канонічний mesh → WebGL → Cycles на поточному комп’ютері. Продакшн-інфраструктура з ARCHITECTURE.md залишається цільовою.

## Рішення

- React/Three.js і локальний Node/Express сервер на 127.0.0.1:4173. Vite працює як middleware. Сервер перевіряє Host, Origin і спеціальний заголовок мутацій; не призначений для мережевого розгортання.
- Імпорт у ізольованому Worker з timeout 60 с і повторним використанням прогрітого воркера та heap 256 MiB. SVGLoader парсить криві; власний pipeline дискретизує, перевіряє перетини та будує внутрішню фаску. Вибір kernel ще не остаточний.
- Канонічний mesh передається як числові масиви JSON у локальному прототипі. Ці самі vertices/indices/normals читають WebGL і Blender. GLB, tangents та остаточні UV бічних граней відкладені до текстур.
- Portable Blender 4.3.2 із офіційного download.blender.org у .local/tools. Системні інсталяції не змінюються. Python worker перевіряє ту саму JSON Schema через jsonschema; TS type виведено зі schema через FromSchema.
- Три area lights, стилізована синя студійна підкладка та однорідний фон. HDRI і texture resources у цьому зрізі ще не підтримуються. Браузерний множник інтенсивності експериментальний; Cycles є контрольним результатом. Початковий набір світла налаштований на чисті металеві відбиття й світлий rim, за мотивами перевіреного референсу; це художній preset, а не фізична калібровка.
- На локальній машині виявлено NVIDIA GeForce MX230. Вибір backend: OPTIX → CUDA → інші підтримувані → CPU, за виявленням пристроїв. Помилка запуску GPU не приховується автоматичним CPU-рендером.

## Межі цього зрізу

Простір API /api/prototype відокремлено від майбутнього /api/v1. Немає auth, збереження проєктів, distributed queue, idempotency, lease recovery, семиденного TTL чи анімації. Геометрія та індекс jobs живуть у пам’яті процесу; completed файли зберігаються в .local/jobs. При запуску індекс завершених jobs відновлюється з input/metrics/artifact; незавершені jobs не відновлюються.

Один активний рендер, явне скасування, незмінний input.json і mesh.json на job. Scene hash у прототипі — SHA-256 точного JSON snapshot, без canonical serializer; кеш рендерів не реалізований. Для production contentHash використати канонізацію зі SCENE_SPEC.

Schema profile цього прототипу приймає підмножину v1: texture=null, environment.resourceId=null, styleOrigin=null, bevel<depth/2, не більше 2000 дискретизованих сегментів. Це не розширення чи зміна семантики scene v1; непідтримувані поля відхиляються. JSON Schema source — packages/contracts/schema.ts; scene.schema.json генерується для Python.

Фон автоматично підбирається як легкий HSL-градієнт того самого відтінку, що й колір об’єкта, та зберігається як фактичний похідний колір; окремого background picker немає. Алгоритм OKLCH із версіонуванням ще не реалізовано. Колір, матеріал і transform застосовуються до всього об’єкта. Немає per-part UI, undo/redo, camera pan та автозбереження.

Final profile: 256 samples замість початкових 512 з RENDER_SPEC для локального експерименту. Решта істотних параметрів явно задана в render.py. Caustics вимкнені; спектральна фізика не моделюється. UV бічних поверхонь і гострі кути потребують наступного вдосконалення. Adaptive curve tolerance оцінюється рекурсивною дискретизацією, не є математичним доказом похибки для довільних кривих.

## Перевірки перед розширенням

Потрібні точне калібрування світла між рушіями, перевірка фізичного поглинання, відповідності силуету, більш складні bevel fixtures, тест tangent-space normal maps і пороги якості за затвердженими референсами. Відтворюваний запуск та результати описані в README.md.
