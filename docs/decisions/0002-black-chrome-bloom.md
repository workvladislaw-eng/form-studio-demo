# 0002: Чорний хром із засвітом

Проблема: emissive-пресет світився рівномірно й не відтворював відбиття референса.

Вибір: conductor chrome без emission, три area lights (біло-блакитний key, блакитний fill, теплий rim), чорний фон. HDR half-float target, MSAA 4, bloom strength 0.3, radius 0.25, threshold 0.8 у лінійному просторі. Ці параметри фіксовані для поточного renderer build. OutputPass виконує фінальне перетворення у sRGB.

Альтернативи: emissive не дає потрібної залежності від світла; Cycles потребує окремого тривалого рендера. Залежностей не додано: використано addons встановленого Three.js.

Наслідки: bloom додає GPU-проходи тільки при зміні сцени. Експорт використовує той самий composer у цільовій роздільності, синхронно копіює результат перед відновленням viewport, а кодування виконується після відновлення. Це не апскейл. Прозорий фон не пропонується для цього стилю.

Перевірка: build/typecheck та 15 наявних тестів пройшли; виконано візуальний огляд WebGL. Чисельну відповідність preview/4K та продуктивність на різних GPU ще не виміряно. Не заявляємо фізично точне розсіювання або відповідність Cycles.
